# Cypher queries and algorithms

Every query the product runs, verbatim from `packages/core/queries/`, with what it is for. Graph model: [GRAPH_MODEL.md](GRAPH_MODEL.md). Generated by joining the files, so this page cannot drift from the code.

Algorithms used: **`algo.SPpaths`** (weighted shortest paths, `pathCount: 3`, `costProp` + `maxCost`) on every plan; **full-text index** on `Goal(text)`; `log()` for the risk of an edge; **`algo.pageRank`** and **`algo.WCC`** were verified in Phase 0 (`spikes/out/falkor.json`). Multigraph: `public:<site>`, `tenant:<id>:<site>` and `m2w:<site>` are separate graphs on one instance.

## `explain`

The runs behind one edge: the proof behind a trail.

```cypher
// The runs that walked one edge (the dashboard's "proof" click).
MATCH (a:State {sig: $from})-[e:ACT {key: $key}]->(b:State)
MATCH (st:Step)-[:FROM]->(a), (st)-[:TO]->(b), (st)-[:OF_RUN]->(r:Run)
WHERE st.action_key = $key
RETURN r.id, r.agent, r.mode, st.ok, st.ms, r.started ORDER BY r.started DESC LIMIT 20
```

## `goal`

Record that a screen satisfied a goal.

```cypher
// Semantic memory: this screen satisfied this kind of task. The screen is created if the run never recorded it
// (a slow page can finish loading after the step was judged). Params: id, text, site, sig, url, title, landmarks, now
MERGE (g:Goal {id: $id})
  ON CREATE SET g.text = $text, g.site = $site, g.created = $now
WITH g
MERGE (s:State {sig: $sig})
  ON CREATE SET s.url_template = $url, s.title = $title, s.landmarks = $landmarks, s.first_seen = $now, s.visits = 0
MERGE (s)-[r:REACHES]->(g)
  ON CREATE SET r.count = 0
SET r.count = r.count + 1, r.last_seen = $now
RETURN r.count
```

## `goal_by_id`

The goal screen of a scripted task, by exact id.

```cypher
// A scripted task names its goal by id: the screens that satisfied it, most often first. Params: id
MATCH (st:State)-[r:REACHES]->(g:Goal {id: $id})
RETURN st.sig AS goalSig, r.count AS times
ORDER BY times DESC LIMIT 1
```

## `goals`

Semantic memory lookup: full-text candidates for a task described in words (ranked again in code by word overlap).

```cypher
// Verified on a local FalkorDB (module ver 41803); $text must be built with ftQuery() in graph.ts. Which screens satisfied tasks like this one.
CALL db.idx.fulltext.queryNodes('Goal', $text) YIELD node, score
MATCH (st:State)-[r:REACHES]->(node)
RETURN st.sig AS goalSig, node.text AS goalText, score, r.count AS times
ORDER BY score DESC, times DESC LIMIT 12
```

## `outgoing`

Known actions from one screen, for exploration.

```cypher
// What the map already knows how to do from one screen (hints for the explorer). Params: sig
MATCH (a:State {sig: $sig})-[e:ACT]->(b:State)
RETURN e.key AS key, e.role AS role, e.name AS name, e.nth AS nth, e.ok AS ok, e.fail AS fail, b.sig AS to
ORDER BY e.ok DESC LIMIT 20
```

## `owned_edges`

Edges walked by successful runs of the same task (template screens are shared, so this keeps a route task-specific).

```cypher
// Edges that a SUCCESSFUL run of exactly this task has walked successfully (task memory). Params: task
MATCH (st:Step {ok: 1})-[:OF_RUN]->(r:Run {task: $task, outcome: 'success'}), (st)-[:FROM]->(a:State)
RETURN DISTINCT a.sig AS from, st.action_key AS key
```

## `plan`

The planner. Up to three routes from the current screen to the goal screen, lowest failure risk first, capped by total milliseconds. This is the FalkorDB algorithm call the whole product rests on.

```cypher
// Verified on a local FalkorDB (module ver 41803). Up to three routes from the current screen to a goal screen.
MATCH (s:State {sig: $current}), (g:State {sig: $goal})
CALL algo.SPpaths({sourceNode: s, targetNode: g, relTypes: ['ACT'],
                   weightProp: 'risk', costProp: 'ms', maxCost: $maxMs, pathCount: 3})
YIELD path, pathWeight, pathCost
RETURN [r IN relationships(path) | {key: r.key, to: endNode(r).sig, kind: r.kind, role: r.role, name: r.name, nth: r.nth, slot: r.slot, pre: r.pre,
                                    ok: r.ok, fail: r.fail, ms: r.ms}] AS steps,
       size(relationships(path)) AS hops, pathWeight, pathCost
ORDER BY pathWeight ASC
```

## `report`

Upsert one walked step: creates the two screens and the edge if new, then updates success and failure counts, the running mean latency and the risk.

```cypher
// Verified on a local FalkorDB (module ver 41803). Separate SET clauses do not see each other's writes there,
// so the new counts are computed in WITH and risk is derived from them.
// Upsert one walked step. Params: from, fromUrl, fromTitle, fromLandmarks, to, toUrl, toTitle, toLandmarks,
// key, kind, role, name, nth, label, slot (task slot a typed value comes from, '' if none), pre (JSON fills made before this click, '' if none), ok (0|1), fail (0|1), ms, now
MERGE (a:State {sig: $from})
  ON CREATE SET a.url_template = $fromUrl, a.title = $fromTitle, a.landmarks = $fromLandmarks, a.first_seen = $now, a.visits = 0
SET a.visits = a.visits + 1
MERGE (b:State {sig: $to})
  ON CREATE SET b.url_template = $toUrl, b.title = $toTitle, b.landmarks = $toLandmarks, b.first_seen = $now, b.visits = 0
MERGE (a)-[e:ACT {key: $key}]->(b)
  ON CREATE SET e.kind = $kind, e.role = $role, e.name = $name, e.nth = $nth, e.label = $label, e.slot = $slot, e.pre = $pre,
                e.ok = 0, e.fail = 0, e.ms = 0.0
WITH a, b, e, e.ok + $ok AS ok2, e.fail + $fail AS fail2,
     (e.ms * (e.ok + e.fail) + $ms) / (e.ok + e.fail + 1) AS ms2
SET e.ok = ok2, e.fail = fail2, e.ms = ms2, e.last_seen = $now,
    e.risk = -log((ok2 + 1.0) / (ok2 + fail2 + 2.0)) + 0.05
RETURN e.ok, e.fail, e.ms, e.risk
```

## `run_end`

Close a run with its totals.

```cypher
// Close a run. Params: id, now, outcome ('success'|'failure'), steps, llm, tokens, ms
MATCH (r:Run {id: $id})
SET r.ended = $now, r.outcome = $outcome, r.steps = $steps, r.llm_calls = $llm, r.tokens = $tokens, r.ms = $ms
RETURN r.id
```

## `run_ensure`

Create a run if an MCP client reports a step for a run we have not seen.

```cypher
// A run opened by a client that only calls report() over MCP. Params: id, agent, tenant ('' for public), task, mode, now
MERGE (r:Run {id: $id})
  ON CREATE SET r.agent = $agent, r.tenant = $tenant, r.task = $task, r.mode = $mode, r.started = $now,
                r.outcome = 'running', r.steps = 0, r.llm_calls = 0, r.tokens = 0, r.ms = 0
RETURN r.id
```

## `run_start`

Open a run (episodic memory).

```cypher
// Episodic memory: one agent episode. Params: id, agent, tenant ('' for public), task, mode ('cold'|'map'), now
CREATE (r:Run {id: $id, agent: $agent, tenant: $tenant, task: $task, mode: $mode, started: $now,
               outcome: 'running', steps: 0, llm_calls: 0, tokens: 0, ms: 0})
RETURN r.id
```

## `stats`

Per-mode run averages for the cold-vs-map meter.

```cypher
// Per-map numbers for the cold-vs-map meter.
MATCH (r:Run) RETURN r.mode AS mode, count(r) AS runs, avg(r.steps) AS steps, avg(r.ms) AS ms, avg(r.llm_calls) AS llm
```

## `step`

Record one step of a run and link it to the run and to the screens it left and reached.

```cypher
// Episodic memory: one step of a run, linked to the run and to the states it left and reached.
// `to` is the edge's target when the step walked an edge (the EXPECTED state for a failed map step), else the current state.
// Params: run, i, key, ok (0|1), ms, source ('map'|'llm'), observed, from, fromUrl, fromTitle, fromLandmarks,
// to, toUrl, toTitle, toLandmarks, now
MATCH (r:Run {id: $run})
MERGE (a:State {sig: $from})
  ON CREATE SET a.url_template = $fromUrl, a.title = $fromTitle, a.landmarks = $fromLandmarks, a.first_seen = $now, a.visits = 0
MERGE (b:State {sig: $to})
  ON CREATE SET b.url_template = $toUrl, b.title = $toTitle, b.landmarks = $toLandmarks, b.first_seen = $now, b.visits = 0
CREATE (st:Step {run: $run, i: $i, action_key: $key, ok: $ok, ms: $ms, source: $source, observed: $observed})
CREATE (st)-[:OF_RUN]->(r), (st)-[:FROM]->(a), (st)-[:TO]->(b)
RETURN st.i
```
